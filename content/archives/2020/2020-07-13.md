## 14:00

The team decided to move forward with python3 in the test environment. Javaria ██████
and I updated the version of python on houcicddev11 to python3.  I removed python2-pytest
and saltdk (dependency).  Installed python36-paramiko.

Created a system-wide symlink

`alternatives --install /usr/bin/py.test pytest /usr/bin/py.test-3.6 99`.

Installed another dependency

`yum install python36-yaml`

All of these changes require that the `saltdk` package be updated to support
python 3.

The host `houcicddev11` was manually updated to work using the steps outlined above.

I opened an issue in `img-instance-builds` for the missing `at` package in eog-centos7-vmware.
