Setting up Salt-API for simple sandbox deployments
--------------------------------------------------

Due to errors in the ldap setup we are using `pam` as the auth method
This means:

1. must manage `external_auth.conf` file in /etc/salt/master.d

2. must use `setfacl -m u:slt800:r /etc/shadow` for pam to work

    a. `/etc/shadow` perms are reset anytime someone runs `passwd`

3. `external_auth.conf` must have restrictions on which modules can be run by api user.

4. since vmware cloning and deploying can take a while, use `runner_async`.  
It will return jid that the caller can then reference for completion.

5. must create local user `isv000` for all api calls from iServer.

```
external_auth.conf example:
external_auth:
  pam:
    isv000:
      - '*':
        - test.ping
      - '@runner':
        - 'manage.*'
        - 'cloud.profile'
        - 'jobs.print_job'
        - 'jobs.exit_success'
```
